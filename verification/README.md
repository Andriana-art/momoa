# Vérifications avant remise

Contrôles effectués le 14 novembre 2026 sur le [site publié](https://andriana-art.github.io/momoa/).

| Critère | Vérification |
| --- | --- |
| Maquettes | Mise en page, images, couleurs et polices comparées aux maquettes Figma. Quelques ajustements sont conservés pour la lisibilité et les crédits. |
| Responsive | Pages testées de 320 à 1920 px, avec les menus, le formulaire et le changement de langue. |
| Bootstrap | Non utilisé ; son usage est facultatif. |
| Code | HTML sémantique, styles communs et textes bilingues regroupés dans les sources. |
| HTML et CSS | Aucune erreur avec Nu HTML Checker et le validateur CSS officiel W3C exécuté localement. Le CSS comporte 11 avertissements. |
| SEO | Titres, descriptions, langues, hiérarchie des titres et textes alternatifs vérifiés. |
| Accessibilité | Clavier, focus, libellés du formulaire et contrastes contrôlés ; aucune violation détectée avec axe. Ces tests restent partiels. |
